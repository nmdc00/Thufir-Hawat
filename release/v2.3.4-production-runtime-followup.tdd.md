# TDD: Production Runtime Follow-Up — v2.3.4

`v2.3.4` is a follow-up patch to `v2.3.3`.

Production proved two remaining gaps after `v2.3.3`:

1. `PositionHeartbeat` still logged `failed to load mids: 429 Too Many Requests` on cold start when no shared mids cache existed yet.
2. `LLM execution context missing; defaulting to FULL_AGENT` still appeared from background mentat paths even after the Telegram relevance pre-screen was wrapped.

## Release Contract

- Heartbeat can derive a fallback mark from live position payloads when `getAllMids()` fails.
- If every open position has a fallback mark, heartbeat does not emit a noisy mids warning on cold-start rate limits.
- Background mentat scan role calls run under explicit `LIGHT_REASONING` context.
- Background mentat quick-fragility calls run under explicit `LIGHT_REASONING` context.
- Background alert enrichment runs under explicit `LIGHT_REASONING` context.
- Background reflexivity narrative snapshots run under explicit `LIGHT_REASONING` context.
