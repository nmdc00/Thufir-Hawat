# Validation Plan: Exit Lifecycle Redesign — v2.3.7

## Purpose

This change alters the live position-management control loop. Unit coverage is necessary but not sufficient; we must prove the runtime seam that actually owns open positions.

## Validation Contract

We are validating six invariants on the exact branch that will later be promoted:

1. TTL is review-only, never a direct close reason
2. hard invalidation still closes immediately
3. emergency risk still closes immediately
4. generic heartbeat triggers no longer place exit orders on their own
5. dynamic profit protection is the only discretionary system path beyond invalidation/emergency
6. LLM review can modify but not independently full-close

## Required Proof Cases

### Case 1. TTL review-only behavior

Proof:

- expired TTL with no consultant does not place a reduce-only order
- expired TTL with consultant `hold` does not place a reduce-only order
- expired TTL with consultant `update_invalidation` does not place a reduce-only order
- policy `time_stop_at_ms` is extended forward each time

### Case 2. Invalidation authority preserved

Proof:

- a long closes when `mark <= invalidation_price`
- a short closes when `mark >= invalidation_price`

### Case 3. Generic trigger authority removed

Proof:

- `time_ceiling` no longer closes
- `pnl_shift` no longer closes
- `volatility_spike` no longer reduces
- `liquidation_proximity` below the emergency threshold no longer closes by itself

### Case 4. Emergency authority preserved

Proof:

- `liqDistPct < 2` still issues a reduce-only market close

### Case 5. Dynamic profit protection path

Proof:

- extension alone does not act
- deterioration alone does not act
- extension plus deterioration can tighten invalidation
- stronger extension plus deterioration can partially reduce
- terminal extension failure can fully close

### Case 6. LLM review authority narrowing

Proof:

- consultant schema no longer accepts `close`
- heartbeat review does not have a consultant-only full-close path
- fallback still returns safe `hold`

## Promotion Gate

Do not promote to `main` unless all six invariants are proven on the exact integration SHA that will be promoted.
